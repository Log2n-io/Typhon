## Engine findings surfaced by the agents and by building the eval

1. **A field added at a higher revision cannot be given a default for existing rows through the documented bootstrap.** Adding a
   field is a compatible change (zero-fill), so a registered `RegisterMigration` function is never called, and `DatabaseEngine.Open`
   / `AddTyphon` offer no hook to register one before components are registered anyway. The T07 agent fell back to
   `TyphonOptions.Seed` guarded by `DatabaseSchema.Inspect`, and noted the crash window: a crash between the schema migration and the
   seed commit leaves the rows at 0 for good.
2. **`DatabaseEngine.Open` fails when the database's parent directory does not exist** ("Database Directory … does not exist").
   Three agents of ten added a `Directory.CreateDirectory` workaround.
3. **`Commit()` on a Versioned component is last-writer-wins unless a conflict handler is passed.** Agents found it in the docs and
   handled it; the reference trap lost 116 of 200 concurrent increments. The guide's table says "conflict-detected", which reads as
   protection.
4. **Doc drift:** the subscriptions guide's `Replicate` example writes through a span without `MarkDirty`; the guide example's
   comment claims the move is never persisted without it, while a clean close does persist it (only crash recovery loses it).
